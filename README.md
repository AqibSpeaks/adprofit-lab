# AdProfit Lab — Pro Workspace Preview

Upload `index.html` to the root of your existing `adprofit-lab` GitHub repository. Or copy all the contents of `adprofit-lab-pro-index.html` into your repository root `index.html`.

Includes existing calculators, guides, Formspree endpoint, Lemon Squeezy checkout link, and three new Pro preview features: multi-campaign analysis, browser-local project saving, CSV export.

**Not a paid-access system.** localStorage is device/browser-specific and is not secure subscriber storage. No login, webhook verification, or paid entitlement enforcement is implemented. Do not promise purchasers private accounts or cross-device sync.

Manual checks: (1) open ROAS and UTM tools; (2) add two campaigns and check totals; (3) save then reload a project; (4) export CSV; (5) check signup form endpoint; (6) verify checkout link; (7) test mobile navigation.
